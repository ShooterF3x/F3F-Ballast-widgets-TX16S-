# 🪂 F3F Ballast Manager - EdgeTX Widget

Color touch-screen widget for EdgeTX radios (TX16S) dedicated to F3F. Real-time calculation of optimal ballast distribution based on wind speed to preserve your target CG.

## 📁 Installation
1. Copy the **`ballast`** folder into `/WIDGETS/` on your SD card (`/WIDGETS/ballast/main.lua`).
2. On your radio, add the **BALLAST** widget to a main screen.

## 🕹️ Usage
- **[PAGE]** : Switch pages (VOL, CONFIG, SOUTES, GESTION).
- **Rotary encoder** : Scroll through options.
- **[ENT]** : Toggle value editing mode (red highlight).
